## 📝 Comandos Útiles

### Detener los servicios:
Presiona `Ctrl + C` en cada terminal donde se están ejecutando los servicios

### Reiniciar backend:
```bash
cd server
npm start
```

### Reiniciar frontend:
```bash
npm run serve
```

### Verificar base de datos:
```bash
cd server
node verificar_db.js
```
